# Automation roadmap

V1 now automates: checkout -> payment verification -> entitlement -> protected delivery -> optional email -> dashboard.

V2 should add: durable Postgres/Neon order records, product analytics, AI-generated post-purchase intelligence reports, customer segmentation, and compliant lifecycle messaging.

Do not add mass unsolicited outreach automation. Use only contacts/channels for which the applicable lawful basis and marketing permissions exist.
